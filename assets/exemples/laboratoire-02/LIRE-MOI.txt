MQT-2101, laboratoire 02 : auditer une prévision de livraison

1. Décompressez le ZIP et ouvrez laboratoire-02.Rproj.
2. Lisez data/dictionnaire-livraisons.md.
3. Ouvrez rapport-labo-02.qmd dans RStudio, indiquez vos noms et cliquez sur Render.
4. Suivez le guide de la mission; construisez vos blocs de code et vos textes.
5. Redémarrez R, cliquez sur Render, ouvrez le HTML et conservez le dossier complet.

Mission : nouvelles données entièrement simulées de livraison au Québec.
Données : data/livraisons_regionales_quebec.csv (96 lignes, sept colonnes).
Apprentissage : dates avant le 1er octobre 2025; validation : autres dates.
Deux modèles à comparer : une droite et un modèle quadratique.
Variable réponse : durée en minutes. Variable explicative : distance en kilomètres.
L072 a une panne confirmée; ce n'est pas une erreur de saisie.
Indiquez votre choix avant d'examiner les durées de validation.
Comparez ensuite les erreurs et répondez aux trois affirmations du guide.
Les prolongements restent facultatifs.

Le ZIP contient le projet, le début de rapport, ce fichier, le dictionnaire,
le CSV de mission et une aide R complète sur un ancien exemple différent :
aide-regression.R et data/achalandage_saturation_quebec.csv.
R, Quarto et tidyverse sont nécessaires.
Gardez les fichiers dans le dossier décompressé pour que les chemins fonctionnent.
Après une tentative, utilisez l'aide au besoin et adaptez les variables et les unités.

Guide publié :
https://aureliennicosiaulaval.github.io/MQT-2101/modules/atelier-02-regression/guide-atelier.html
Consultez ce guide pour les étapes de la mission, les trois affirmations
à auditer et les résultats attendus.

Le laboratoire est formatif. Les données du cours sont inadmissibles pour le
mini-rapport 1, qui utilise un jeu extérieur approuvé. La validation essentielle
au laboratoire reste facultative dans ce travail évalué selon sa grille.
