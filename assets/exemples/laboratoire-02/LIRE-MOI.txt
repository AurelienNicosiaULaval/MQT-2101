Laboratoire 02 : choisir et défendre un modèle de régression
MQT-2101, Université Laval

1. Décompressez le dossier avant de l'ouvrir.
2. Ouvrez laboratoire-02.Rproj dans RStudio ou Positron.
3. Ouvrez rapport-labo-02.qmd et indiquez vos noms.
4. Cliquez sur Render. Le début de rapport fonctionne avant l'analyse.
5. Suivez le guide de la mission, ajoutez vos blocs et relancez Render.

Guide :
https://aureliennicosiaulaval.github.io/MQT-2101/modules/atelier-02-regression/guide-atelier.html

R, Quarto et le package tidyverse doivent être installés.
Au besoin, installez tidyverse une seule fois dans la Console :
install.packages("tidyverse")
N'ajoutez pas l'installation au rapport.

Gardez le QMD à la racine et le CSV dans data/.
Les données sont simulées pour l'enseignement.
L'importation est fournie. Vous choisissez l'explicative, la variante,
le code d'analyse et la manière de présenter votre conclusion.

Le laboratoire est formatif, distinct du mini-rapport 1.
Conservez le QMD, le HTML et data/ ensemble.
Avant de terminer, redémarrez R, faites Render sans préparation dans la
Console, puis ouvrez le HTML pour vérifier le résultat.
