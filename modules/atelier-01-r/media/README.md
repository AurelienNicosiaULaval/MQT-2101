# Médias - Atelier 01

Ce dossier sert à préparer les médias publics de l'atelier.

## Sous-dossiers

- `videos/` : vidéos courtes intégrées aux repères, si nécessaire.
- `pdf/` : supports PDF générés à partir des contenus Quarto.

## Règles

- ne pas publier de documents privés ou protégés sans validation;
- privilégier des vidéos courtes;
- garder le même numéro de repère entre la vidéo et le support correspondant;
- documenter toute source ancienne utilisée.
