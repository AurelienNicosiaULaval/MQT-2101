# Données de l'atelier 01

`ventes_pme_quebec.csv` est un jeu de données simulé pour le cours MQT-2101.

Le fichier représente les ventes mensuelles d'une PME québécoise fictive dans cinq succursales.

Variables principales :

- `mois` : mois d'observation;
- `succursale` : ville de la succursale;
- `region` : région administrative;
- `campagne_locale` : présence ou absence d'une campagne locale;
- `depenses_marketing` : dépenses marketing du mois;
- `clients` : nombre de clients;
- `panier_moyen` : panier moyen en dollars;
- `ventes` : ventes mensuelles en dollars;
- `delai_livraison_jours` : délai moyen de livraison;
- `ruptures_stock` : nombre de ruptures de stock observées;
- `satisfaction` : score moyen de satisfaction sur 10;
- `taux_retour` : proportion de retours.

Les données ont été simulées pour un usage pédagogique dans l'atelier.
