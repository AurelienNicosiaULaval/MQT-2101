# Médias du module 08

Le lot `module-08-pdf-2026-11-11.zip` contient les cinq supports de capsule, leurs versions annotées et la synthèse. Les onglets donnent accès aux vidéos et aux supports PDF, PDF annotés et HTML.

Le thème UL/FSA et les composants des modules 04 et 06 sont repris. Le guide séparé `interne/guide-preparation-module-08.md` contient les références détaillées, notes d’animation, hypothèses complémentaires et correspondance avec les anciennes sources. La synthèse termine par les crédits nécessaires. Le cahier facultatif est un document HTML avec code R et projet autonome, distinct du parcours projeté.

Les données sont simulées. Les anciens PDF et données de tiers ne sont pas redistribués. Les médias sont présentés dans l’ordre Vidéo, PDF, PDF annoté, HTML; les PDF annotés conservent les annotations originales.
