# Médias du module 07

Version locale du 3 novembre 2026. Quatre capsules principales, un complément Holt facultatif et une synthèse sont fournis en HTML et PDF. Les PDF proviennent des diapositives HTML. Les vidéos et les PDF annotés des quatre capsules principales sont disponibles. Chaque capsule présente les onglets Vidéo, PDF, PDF annoté et HTML, dans cet ordre. Le complément Holt et la synthèse restent proposés en PDF et HTML.

Après le rendu Quarto des six supports, `scripts/33_export_module07_pdfs.cjs` exporte les PDF, vérifie les trois colonnes des cartes à l’écran et à l’impression et synchronise les copies du module et de `docs/`, ainsi que le lot téléchargeable annoncé dans `capsules.qmd`. Le script attend la mise en page d’impression, les polices, les équations et les images. Il conserve les captures de chaque diapositive dans un dossier de contrôle sous `output/`. L’inspection visuelle des PDF complète cette commande.

Les diapositives utilisent le thème UL/FSA existant. Les références détaillées, notes d’animation, sources anciennes et décisions de déplacement sont dans `interne/guide-preparation-module-07.md`, exclu du site. La synthèse termine par une diapositive de références et crédits. Les données sont entièrement simulées. Les sources anciennes protégées ne sont pas redistribuées.

Les vidéos ont été retrouvées et vérifiées sur la chaîne YouTube d’Aurélien Nicosia. Leurs identifiants sont MR7lv5m5A8U, WBqpUEJTrC0, E1QwIkisdKk et AMla4tFwuHA, pour les capsules 1 à 4. Les copies de diffusion des quatre PDF annotés sont identiques aux originaux fournis par l’enseignant; leurs noms utilisent le suffixe stable `-annote.pdf`. Les originaux sont conservés. Les annotations gardent la composition de l’enregistrement, légèrement différente des supports harmonisés.

Le lot `module-07-pdf-2026-11-03-harmonise.zip` contient dix PDF : les six supports harmonisés et les quatre versions annotées. Les liens individuels permettent aussi de télécharger chaque PDF. Aucun média n’est ajouté au complément Holt sans fichier ou vidéo effectivement disponible.

Le cahier facultatif complements.qmd et son projet complements-lissage.zip développent les méthodes avancées de l’ancienne séance. Il est indépendant des six supports PDF/HTML et ne crée aucune activité obligatoire.
