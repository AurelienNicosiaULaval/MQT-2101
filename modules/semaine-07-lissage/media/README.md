# Médias du module 07

Version locale du 3 novembre 2026. Quatre capsules principales, un complément Holt facultatif et une synthèse sont fournis en HTML et PDF. Les PDF proviennent des diapositives HTML. Aucune vidéo ni version annotée n’est disponible: seuls les onglets PDF et HTML sont affichés.

Après le rendu Quarto des six supports, `scripts/33_export_module07_pdfs.cjs` exporte les PDF, vérifie les trois colonnes des cartes à l’écran et à l’impression et synchronise les copies du module et de `docs/`, ainsi que le lot téléchargeable annoncé dans `capsules.qmd`. Le script attend la mise en page d’impression, les polices, les équations et les images. Il conserve les captures de chaque diapositive dans un dossier de contrôle sous `output/`. L’inspection visuelle des PDF complète cette commande.

Les diapositives utilisent le thème UL/FSA existant. Les références détaillées, notes d’animation, sources anciennes et décisions de déplacement sont dans `interne/guide-preparation-module-07.md`, exclu du site. La synthèse termine par une diapositive de références et crédits. Les données sont entièrement simulées. Les sources anciennes protégées ne sont pas redistribuées.

Après enregistrement et vérification des annotations, intégrer les médias réels selon la recette du projet: Vidéo, PDF, PDF annoté, HTML. Conserver les PDF annotés originaux et vérifier leur concordance si le support change.

Le cahier facultatif complements.qmd et son projet complements-lissage.zip développent les méthodes avancées de l’ancienne séance. Il est indépendant des six supports PDF/HTML et ne crée aucune activité obligatoire.
