# Données de la semaine 01

`diagnostic_succursales.csv` est un jeu de données simulé pour introduire le diagnostic statistique en contexte d'affaires.

Chaque ligne représente une succursale fictive dans un jeu de données pédagogique.

Variables :

- `succursale` : ville de la succursale;
- `region` : région administrative;
- `ventes_mensuelles` : ventes mensuelles en dollars;
- `clients` : nombre de clients;
- `panier_moyen` : panier moyen en dollars;
- `satisfaction` : satisfaction moyenne sur 10;
- `delai_livraison_jours` : délai moyen de livraison;
- `ruptures_stock` : nombre de ruptures de stock.

Les données ont été générées avec `scripts/05_create_semaine_01_data.R`.
