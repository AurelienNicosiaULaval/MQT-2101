## Pratique formative

Les questionnaires ne sont pas évalués. Ils servent à repérer les notions à consolider avant les examens.

[Régression](questionnaire-regression.llms.md)

Vérifier l'interprétation, les diagnostics et les sorties R avant l'intra.

[Séries chronologiques](questionnaire-series-chronologiques.llms.md)

Réviser tendance, saisonnalité, horizon et mesures d'erreur avant le final.

## Produire un mini-rapport solide

La trace finale doit montrer une démarche compréhensible, reproductible et défendable.

1.  01

    ### Choisir une question

    Définir une question d'analyse liée à un contexte d'affaires ou d'organisation.

2.  02

    ### Valider les données

    Faire approuver le jeu de données avant de construire l'analyse.

3.  03

    ### Analyser dans Quarto

    Présenter le code, les graphiques, les résultats et l'interprétation dans un document reproductible.

4.  04

    ### Déclarer l'IA

    Documenter l'usage de l'IA lorsque l'aide influence le code, l'analyse, l'interprétation ou le texte.

## Règles d'utilisation de l'IA

Les règles détaillées sont décrites dans la page [IA et apprentissage](../ressources/ia.llms.md). Pour les activités liées au cours, le [GPT du cours](https://chatgpt.com/g/g-6a0b2ec33d948191ad25b2f247b15de1-analyse-et-modelisation-des-donnees?ref=mini) est recommandé. Les mêmes règles s'appliquent à tout outil autorisé.

Examens

IA non permise pendant les examens individuels en personne.

Mini-rapports

IA permise, mais déclarée lorsque son usage influence le livrable.

Travail personnel

IA permise comme outil d'apprentissage, avec responsabilité de comprendre et vérifier.
