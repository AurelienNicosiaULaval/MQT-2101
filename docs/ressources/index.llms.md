## GPT du cours

Pour les activités liées au cours, utilisez le GPT du cours. Il sert de tuteur pour comprendre, déboguer, vérifier et réfléchir. Il ne remplace pas le travail personnel.

[Ouvrir le GPT du cours](https://chatgpt.com/g/g-6a0b2ec33d948191ad25b2f247b15de1-analyse-et-modelisation-des-donnees?ref=mini) [Voir les règles IA](ia.llms.md)

### Demander une explication

Par exemple : expliquer une sortie R, une hypothèse de modèle ou une erreur dans un code.

### Vérifier une tentative

Fournir son propre code ou son interprétation, puis demander une rétroaction ciblée.

### Rester responsable

Comprendre, vérifier, modifier et défendre tout contenu utilisé dans un travail remis.
