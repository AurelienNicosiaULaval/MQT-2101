# Déclaration d'usage de l'IA

Cette page donne un modèle à intégrer dans un mini-rapport lorsque l'IA a influencé de façon significative le code, l'analyse, l'interprétation, la documentation ou le texte remis.

Final

Assumer le contenu remis

## Quand remplir cette déclaration

La déclaration est nécessaire dès que l'aide de l'IA change un élément remis : code, choix méthodologique, analyse, interprétation, documentation ou texte. Une simple clarification sans effet sur le livrable n'exige pas de retranscrire l'échange.

### Règle pratique

Si l'aide de l'IA a changé ce que vous remettez, ou la manière dont vous l'expliquez, il faut la déclarer.

## Exemples de formulations

Ces exemples montrent le niveau de précision attendu.

### Débogage de code

Nous avons utilisé le GPT du cours pour comprendre une erreur dans une commande `summarise()`. Le code corrigé a été exécuté localement et les résultats ont été comparés au tableau initial.

### Interprétation

Nous avons demandé une relecture critique d'un paragraphe d'interprétation. La formulation finale a été modifiée pour distinguer association et causalité.

### À éviter

Phrase insuffisante : « Nous avons utilisé l'IA pour le rapport. » Elle ne dit pas quelle aide a été obtenue ni ce qui a été vérifié.

## Liste de vérification

Avant la remise, la déclaration doit permettre de comprendre le rôle exact de l'IA dans le travail.

### L'outil est nommé

Par exemple : GPT du cours, ChatGPT ou un autre outil utilisé.

### La tâche est précise

Débogage, reformulation, vérification, comparaison de méthodes ou aide à l'interprétation.

### Les vérifications sont visibles

Code relancé, résultats contrôlés, documentation consultée ou limites ajoutées.

### La responsabilité est affirmée

L'équipe assume le contenu final et peut l'expliquer.

## Si aucune IA n'a influencé le livrable

Insérez simplement la phrase suivante dans la section prévue du mini-rapport.

    ## Déclaration d'usage de l'IA

    Aucun outil d'IA générative n'a influencé le code, l'analyse, l'interprétation, la documentation ou le texte de ce livrable.
