## À retenir pendant la lecture

La régression linéaire doit toujours être reliée à une question précise. Avant d’interpréter les coefficients, vérifiez le graphique, le contexte, les unités et les résidus. Une relation statistique utile pour la décision n’est pas nécessairement une relation causale.
