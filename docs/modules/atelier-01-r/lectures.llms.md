# Lectures - Atelier 01

## Objectif

Les lectures servent seulement d’appui. L’essentiel de l’atelier se fait dans RStudio, avec le fichier de données et le rapport Quarto.

## À revoir avant l’atelier

- unité d’observation;
- type de variable;
- dictionnaire rapide de variables;
- valeurs manquantes;
- moyenne, médiane, somme et proportion;
- graphique de comparaison;
- graphique de relation descriptive;
- différence entre description et explication;
- recommandation préliminaire et limite.

## À revoir après l’atelier

Relisez les notions qui ont posé problème pendant la séance, puis complétez le rapport Quarto avant la remise.
