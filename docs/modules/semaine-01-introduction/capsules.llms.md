# Capsules - Semaine 01

## Objectif

Cette page rassemble les six capsules de la semaine 01. Chaque capsule sert à installer un repère précis avant les démonstrations et les exercices : comprendre le fonctionnement du cours, situer les modèles, lire un tableau, décrire une variable et comparer prudemment.

Pour chaque capsule, ouvrez le support HTML ou PDF, puis réalisez la courte activité proposée. L’objectif n’est pas de tout mémoriser, mais de produire une trace finale courte et claire.
