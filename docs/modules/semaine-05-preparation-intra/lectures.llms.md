## À prioriser

La priorité n’est pas de relire tout le site. La priorité est de refaire des gestes complets :

1.  lire une question;
2.  identifier les variables;
3.  produire un graphique;
4.  ajuster un modèle;
5.  interpréter le résultat;
6.  nommer une limite.
