# Roadmap de refonte du cours MQT-2101

Cette roadmap résume les prochaines étapes pour refaire le cours autour d'un site Quarto appliqué, orienté administration, décision d'affaires et R.

## Priorités

1. Publier le site Quarto sur GitHub Pages.
2. Cartographier l'ancien matériel sans publier les archives privées.
3. Finaliser la progression pédagogique par semaine.
4. Construire les jeux de données du cours.
5. Rédiger les semaines, ateliers, évaluations et ressources.

## Phases

| Phase | Résultat attendu |
|---|---|
| 0. Stabiliser le dépôt et le site | Site publié, dépôt propre, archives privées ignorées |
| 1. Cartographier l'ancien matériel | Table de correspondance entre ancien et nouveau cours |
| 2. Définir la progression pédagogique | Objectifs, compétences et livrables par semaine |
| 3. Construire les données du cours | Jeux de données propres et documentés |
| 4. Rédiger les semaines | Notes, capsules, exercices et mini-cas |
| 5. Développer les ateliers | Ateliers guidés et appliqués |
| 6. Refaire les évaluations | Questionnaires, examens et grilles |
| 7. Produire les ressources | Guides R, Quarto, statistiques et modélisation |
| 8. Tester et améliorer | Site fiable et prêt pour l'enseignement |

Voir la version détaillée dans `roadmap.qmd`.
